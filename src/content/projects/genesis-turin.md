Proyecto de visualizador para diez canciones, creado junto a Julieta Tolosa. Explora una experiencia visual basada en la experimentación técnica y el procesamiento híbrido: el video se manipula digitalmente y luego se envían señales a hardware analógico para intervenir físicamente la imagen, generando una estética distinta para cada tema a partir de la tensión entre el código digital y la textura orgánica del hardware.

Colaboración: **Julieta Tolosa**.
